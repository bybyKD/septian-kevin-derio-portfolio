logic-lab is an experimental TypeScript playground: a growing collection of interactive logic and tool prototypes built with React and Vite. It started as a way to prototype how people could learn and reason about code — and it keeps growing whenever there is a new interaction pattern worth trying.

## What it is

- **Interactive learning sections** — landing modules covering what logic is, debugging, code tracing, and a "four languages" comparison
- **Code lab** — a code editor coupled with a code trace and an execution timeline, so every step a snippet takes is visible
- **Challenges** — a challenge flow with an algorithm builder, choice cards, and scroll-to-challenge navigation
- **Personal dashboard** — learning dashboard with module cards, a progress ring, skill bars, and stat cards
- **Admin area** — a dashboard with a participant table and participant detail views to manage the lab

## How it's built

The repo is a lean Vite + React + TypeScript app. Components are grouped by purpose rather than by page: `components/challenge/` holds the challenge flow, `components/code/` the editor and tracing tools, `components/landing/` the marketing-oriented sections, and `components/dashboard/` plus `components/admin/` the two main experiences. Two docs lay out the plan and product requirements (`docs/LOGIC_LAB_PLAN.md` and `docs/LOGIC_LAB_PRD.md`).
